# Security policy

Please report vulnerabilities privately, not in a public issue: use
[Report a vulnerability](https://github.com/unblockingapi/mcp/security/advisories/new)
on this repository's Security tab. We reply within a few working days.

This covers the MCP server in this repository, both the npm package
`@unblockingapi/mcp` and the hosted server at `https://mcp.unblockingapi.com/mcp`.
Only the latest release gets fixes.
